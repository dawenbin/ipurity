## 怎么算通过

- 表里每一行的**级别**和**得分**跟页面上一致 → 判定层没问题。
- **未评级**的行：级别那格写「未评级」、得分那格是「—」，而且它排在所有有级别的行之后 → 没有样本的行不该参与排名。
- **不可路由**的行：级别那格写「不可路由」，也不参与排名。
- 页面顶上统计条的数字 == 上面「统计条应该是」那一行 → 汇总没问题。
- 结果行数 == 批次规模里的数字 → 解析层没漏行（一行多个 IP 也要全收）。
- 出现任何「未识别」都是 bug（这批里没有该认不出的东西）。

## 界面上自检覆盖不到、值得顺手看的

- 详情面板**不再有**「建议拿」那一格（工具只看到 /24 这一层，挑不出更该拿的那个）。
- 不可路由的行排在最末，级别那格写「不可路由」，不是「—」。
- 「未识别/缺数据」那格的数字 = 12（这批全是不可路由），点它能筛出这 12 行。
- 导出的排名 CSV 里**没有**「建议拿的 IP」这一列，列数仍然对齐。
- 中英切换：`不可路由` ↔ `Unroutable`，`级别说明`、`来源`、`得分` 一列都不留中文。
